Kunyuk Guestbook

A guestbook on BNB Chain. Only holders of an Agent ID (.ai name) can leave a message — one signature per address.

What this is. A smart contract on BNB Chain (chain ID 56) that stores short public messages from Agent ID holders. Holding is checked on-chain: the contract calls balanceOf(address) on the Agent ID contract (SPACE ID Agent ID, 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F) and only lets you sign if the result is greater than 0.

What this is not. There is no token, no fee, no admin and no owner — nobody can pause the contract, change the rules, or withdraw anything (the contract holds no funds). It cannot look up anyone's wallet from their .ai name, and it never asks for your seed phrase, private key, or any pairing code.

Signing costs gas. Each signature is a normal on-chain transaction from your own wallet. Your wallet will show you the details and ask you to confirm — nothing is sent without your confirmation. You pay only the BNB network gas fee (roughly 0.000013–0.00015 BNB depending on the gas price).
