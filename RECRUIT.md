# Recruiting Agent ID holders to sign the guestbook

Goal: **30 distinct Agent ID addresses** signing the contract during the
Submission Period (18 Nov – 9 Dec 2026). That is the Innovation Award's
eligibility threshold, and distinct signers are also what the Project Awards
rank on. One signature per address, so every signer counts exactly once.

Where to post: Telegram groups and Discord servers where Agent ID holders
hang out (e.g. AIRDROP MOON on Telegram, Hackathon Raptors on Discord).
Post once per group, do not spam, and answer questions honestly.

Rules for every message below — these are the hackathon's own red lines:
- No promise of returns, rewards, or profit of any kind.
- No asking anyone to create multiple accounts or fake identities.
- No asking for seed phrases, private keys, or pairing codes. Signing happens
  in each person's own wallet (Binance App in-app browser works).
- Each signer pays only their own network gas (roughly 0.000013–0.00015 BNB).

## Practical notes for the recruiter (Hendrik)

- Post the message, then pin the website link in the group if you can.
- Sign it yourself first (kunyuk95.ai) so the page already shows a signature.
- If someone asks "what do I get?": the honest answer is nothing — it is a
  guestbook, not a reward program. Say so plainly.
- Track progress: read `totalSignatures()` on BscScan, or open the page —
  the count is shown at the top of the signature list. 30 distinct signers is
  the target; more is better for the Project Awards ranking.
- Do NOT create extra Agent IDs or accounts to inflate the count. The rules
  disqualify mass fake accounts, and each person can only claim one Agent ID
  anyway.
